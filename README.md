# 태번 체스

실리태번 채팅방에 연결되는 모바일용 체스 확장 프로토타입입니다. 현재 열려 있는 채팅의 캐릭터와 사용자 이름을 표시하고 기보와 대국 대화를 해당 채팅에 저장합니다.

## 설치

1. SillyTavern에서 확장 메뉴를 열고 **Install extension**을 선택합니다.
2. 이 GitHub 저장소의 HTTPS 주소를 붙여 넣고 설치합니다.
3. 채팅방을 열고 입력창 옆 **마법봉 → 태번 체스**를 누릅니다. 오른쪽 아래 **♞ 체스** 버튼으로도 열 수 있습니다.

## 프로토타입 체험

코칭 예시에서 백의 f3 나이트를 g5로 옮길 수 있습니다. 되돌리기, 기보 복기, 단계별 힌트, 대화창과 전체 대화 보기를 체험할 수 있습니다. 설정에서 테마와 기물 디자인을 바꿀 수 있습니다. 대국은 예시 수순으로 진행되며 기본값은 예시 대사입니다.

## 확장 설정

확장 탭의 **태번 체스**에서 실행 버튼을 켜거나 끌 수 있습니다. 연결 프로필을 선택하면 힌트가 켜진 대국과 복기에서 입력한 메시지를 해당 프로필로 전송합니다. 힌트를 끈 대국에서는 예시 대사를 사용합니다. **현재 채팅의 체스 데이터 삭제**는 확인 후 해당 방의 기보와 대국 대화를 지웁니다.

## 저장소 구성

저장소 최상위에 manifest.json, index.js, style.css, board.js 및 FONT-LICENSE.txt를 함께 둡니다. 빌드 과정 없이 설치됩니다. 기물 윤곽선의 원본은 DejaVu Sans이며 라이선스는 FONT-LICENSE.txt에 포함되어 있습니다.
