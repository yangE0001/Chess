# 태번 체스 0.5.1

실리태번 채팅방에서 캐릭터와 체스를 두는 모바일 대응 확장입니다.

## 설치 및 업데이트

이 폴더의 파일을 GitHub 저장소 최상위에 올립니다. 실리태번의 **확장 → 확장 프로그램 설치**에 저장소 URL을 입력하세요. 기존 설치는 확장 프로그램 관리에서 업데이트한 뒤 새로고침합니다. 마법봉 메뉴의 **태번 체스**로 현재 채팅의 대국을 엽니다.

## 대국과 코칭

백·흑·랜덤을 선택합니다. 자유대국에서는 타이머를 설정할 수 있습니다. 이동할 기물과 목적지를 차례로 누르세요. 내 수가 먼저 판에 표시되고 상대의 생각 시간이 지난 뒤 응수가 표시됩니다. 상대 차례에는 상대 시계가 흐릅니다. 승격 때는 원하는 기물을 고릅니다. 내장 엔진은 알파베타 탐색으로 양쪽의 응수를 읽고 수를 고릅니다. 힌트 버튼은 먼저 단서를 주고 다시 누르면 판에 한 가지 가능한 수를 표시합니다. **수 시험하기**에서는 본판을 보존한 채 가상 수순을 직접 둘 수 있습니다. **원래 판으로**를 누르면 돌아옵니다. 코칭에서는 실제로 둔 수와 응수에 관한 해설을 제공합니다.

체크메이트, 스테일메이트, 기물 부족, 시간 종료를 판정합니다. 동일 국면 3회 및 50수 조건은 자동 무승부로 처리합니다. 되돌리기를 누르면 내 마지막 착수 직전으로 돌아갑니다.

## 용어로 배우기

힌트를 켜면 두 모드에서 내가 둔 수가 포크·절대 핀·디스커버드 어택·캐슬링·기물 전개 등으로 확인될 때 이름과 이유가 표시됩니다. 등록된 오프닝은 기보의 시작 수순이 일치할 때 소개합니다. 힌트를 끄면 라이브 전술 안내를 숨깁니다. 복기에서는 각 수의 용어와 엔진 예상 수순을 다시 확인할 수 있습니다. 코칭 대화에서 용어의 뜻을 질문할 수 있습니다.

## 캐릭터 대화

확장 설정에서 현재 채팅 연결, 저장된 연결 프로필 또는 로컬 코칭을 선택합니다. 모델 연결 시 캐릭터 카드와 최근 채팅 장면을 대국 대화에 반영합니다. 자동 대사와 입력한 질문은 연결된 모델을 호출합니다. 힌트 OFF에서는 현재 판의 위치와 추천수를 대화 요청에서 제외하고 잡담을 이어갑니다. 로컬 코칭은 API 호출 없이 기보에 근거한 설명을 표시합니다. 기존 설치의 로컬 설정을 그대로 사용하는 경우 캐릭터 대화는 **현재 채팅 연결**을 선택해 켤 수 있습니다.

## 저장과 복기

현재 판과 대국 대화를 실리태번의 채팅 메타데이터에 저장합니다. 새 판을 시작하면 직전 판의 기보를 복기 목록에 보관합니다. **복기**에서 현재 판 또는 직전 판을 고른 뒤 자동 재생하거나 한 수씩 이동하세요. 각 수의 포획·체크·승격·포크 등과 전체 요약을 확인하고 그 위치에서 질문할 수 있습니다. 복기에는 백 기준 엔진 평가, 완료된 탐색 깊이와 예상 수순을 표시합니다. 폰 하나의 기본값은 1.00입니다. 모바일용 짧은 탐색이므로 깊이는 기기와 국면에 따라 달라집니다. 현재 채팅의 체스 데이터 삭제는 확인 후 해당 방의 기록을 지웁니다.

클래식 기물의 DejaVu Sans 라이선스는 FONT-LICENSE.txt에 있습니다.

## 상대 난이도

새 대국에서 입문자·초심자·중수·고수·그랜드마스터급을 고릅니다. 기존 대국의 기본값은 중수입니다. 낮은 단계는 얕게 읽고 후보수에 변화를 주며, 높은 단계는 교환과 체크 응수를 추가로 탐색합니다. 최고 단계는 자체 엔진의 최대 탐색 설정이며 공인 등급이나 측정된 Elo를 뜻하지 않습니다. 일반 브라우저에서는 상대가 별도 워커에서 계산합니다. 워커를 시작할 수 없는 환경에서는 짧은 탐색으로 응수합니다. 코칭과 복기 분석은 상대 난이도와 독립적입니다.
